# Changelog

## 1.0.0 — 2026-10-16

First stable release of Light Card.

- Shared multi-entity configuration with responsive tablet tiles and compact rows.
- Automatic layout and optional dashboard view toggle; independent compact appearance overrides.
- State-colored icons, actual light color, subtle glow, optional labels/state/relative last change.
- Capability-aware brightness controls, touch and keyboard interaction, serialized service calls and visible failures.
- Light, switch, helper, fan and automation toggling; button, scene and script activation.
- Collapsible native HA form editor, per-entity name/icon overrides, optional details action.
- HACS packaging, bundled runtime, simulated demo, automated unit/DOM tests and CI/release workflows.

Validation uses simulated HA states and services plus browser inspection. Real Home Assistant editor/device testing remains outstanding.
